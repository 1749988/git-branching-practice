# Git Branching Practice

A learning sandbox for Git branches, commits, merges, and pull requests.

This repository contains a practice guide; it is not an application or a finished software product.

## Suggested exercise

1. Clone this repository and create a branch with `git switch -c practice/first-change`.
2. Add a short note to a new `notes.md` file.
3. Review the changes with `git diff`, then stage and commit the note.
4. Push the branch and open a pull request against `main`.
5. Review the diff, merge the pull request, and inspect the history with `git log --oneline --graph --all`.

## Purpose

Practice small, focused commits, clear commit messages, and reviewing changes before merging.
